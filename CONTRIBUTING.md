# Contributing

Issues and pull requests are welcome. Please:

1. Run the tests (see README, "Build and test").
2. Keep the C++ core and its Python mirror (`src/ovalffr/mask.py`) in step; `tests/test_mask_parity.py` checks it.
3. Say plainly in your PR what you did **not** test (for example "not run on AMD").
4. Note the licence: PolyForm Noncommercial 1.0.0 (source-available, free for noncommercial use).

Most wanted: a Direct3D 11 backend, a Vulkan backend, and reports from real games.
